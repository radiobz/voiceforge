## 二、CRITICAL 级别问题与修复

### C1. 自定义音色 vid 生成两次，wav 文件与注册表 id 不一致

**文件**：`voice_lab.py:250,218`  
**问题**：`create_custom()` 生成第一个 uuid（vid1）命名 wav 文件，但 `registry.add()` 又生成第二个 uuid（vid2）覆盖 entry id。导致：
- 试听 URL `/api/voices/custom/{vid1}/audio` → registry 查不到 → 404，自定义音色试听完全不可用
- 删除音色时删 `{vid2}.wav` → 文件不存在 → wav 文件永久残留磁盘
- TTS 合成用 vid2 能正常工作（隐蔽性强）

**修复**：`create_custom()` 在 entry 中预填 `id` 和 `short_name`，`registry.add()` 优先复用 entry 已带的 id。  
**回归验证**：✅ 上传音色后 wav 文件名 = registry id = ref_wav URL 中的 id，试听返回 200，删除后文件清理干净。

### C2. DELETE /api/voices/custom/{vid} 路径遍历任意文件删除

**文件**：`main.py:84-91`  
**问题**：即使 `registry.remove(vid)` 返回 False，代码仍继续执行文件删除；vid 含 `../` 可穿越目录删除任意 `.wav` 文件。

**修复**：
1. 添加 vid 白名单正则 `^custom_[0-9a-f]{8}$`，不匹配返回 400
2. registry.remove 返回 False 时直接返回，不执行文件删除
3. 删除前用 `os.path.realpath` 校验路径必须在 REFS_DIR 内

**回归验证**：✅ 非法 vid 返回 400；路径遍历被 HTTP 路由层拦截（405）+ 代码层白名单双重防护。

### C3. _tasks / _locks 字典无限增长（内存泄漏）

**文件**：`tasks.py:26-27`  
**问题**：每个合成任务往 `_tasks` 插入 TaskResult（含 segments 列表），但无任何清理机制，长期运行 OOM。

**修复**：添加 `_task_created` 时间戳记录、`_TASK_TTL=3600s`、`_evict_old_tasks()` 函数，在 `get_task()` 中每次调用时清理超过 1 小时的 done/failed 任务（不清理 running/queued）。

### C4. 音乐生成中间 WAV 文件从不删除（磁盘泄漏）

**文件**：`musicgen.py:531-533`  
**问题**：`generate()` 渲染 WAV → 转 MP3 后，中间 WAV 从未删除。40 分钟曲目约 423MB/任务，配乐任务额外产生 2-3 个大 WAV。

**修复**：用 `try/finally` 包裹，`to_mp3()` 后 `os.remove(wav)`；`run_music_adapt` 中的中间 WAV 同样清理。  
**回归验证**：✅ 音乐生成任务目录下只剩 mp3，无 .wav 残留。

### C5. ValueError 未转 HTTPException，业务校验失败返回 500

**文件**：`main.py:68,98,152` 等多处  
**问题**：FastAPI 默认不把 ValueError 映射为 400，所有 `raise ValueError("文件超过上限")`、`raise ValueError("仅支持音频...")` 都返回 500 Internal Server Error。`main.py:67-68` 甚至有一行无意义的 `raise ValueError(str(e)) from e` 原样重抛。

**修复**：注册全局异常处理器 `@app.exception_handler(ValueError)` → 返回 400 + `{"detail": str(exc)}`；删除无意义的重抛代码。  
**回归验证**：✅ 伪造 .pdf/.docx 上传返回 400 友好错误；非法参数返回 400/422。

## 三、HIGH 级别问题与修复

### H1. engines.list_voices() 永远调用 edge，忽略 VFORGE_ENGINE

**文件**：`engines/__init__.py:62`  
**修复**：改为通过 `_engine_module()` 分发，当前引擎有 `list_voices` 则调用之，否则回退 edge。

### H2. mix_with_voice 纯音乐输出仍带 ducking 压音

**文件**：`musicgen.py:625`  
**问题**：`music_bus` 已乘 ducking 包络，除以 gap 后语音段仍被压到 duck/gap（约 71%）。注释写"未压"但实际是带侧链压缩的音乐。

**修复**：`out_music` 直接写原始音乐（仅裁剪到人声时长 + 尾部淡出），不经过 ducking 包络。

### H3. SSE 完成后 EventSource 自动重连死循环

**文件**：`main.py:175-189` + `api.js:68-72`  
**问题**：任务 done/failed 后服务器关闭连接，浏览器 EventSource 默认 3 秒自动重连，形成无限重连。

**修复**：前端 `api.js` 在 `onmessage` 中判断 status=done/failed 时调用 `es.close()`，并添加 `onerror` 处理。

### H4. Pydantic 模型缺少范围/枚举校验

**文件**：`schemas.py` 全文  
**问题**：rate/pitch/volume/duration/emotion/mode/balance/output_format 全部无约束，非法值穿透到下游。

**修复**：添加 `Field(ge=, le=)` 和 `Literal[...]` 约束：
- `text`: min_length=1（不设上限，满足长文本需求）
- `rate`: 0.5~2.0, `pitch`: -50~50, `volume`: 0~2.0
- `emotion_strength`: 0~1.5, `duration`: 10~2400
- `emotion`/`mood`: 6 种情绪 Literal
- `mode`: chill/meditation/ambient/lofi
- `balance`: loud/auto/low, `output_format`: mp3/wav

**回归验证**：✅ 非法 emotion/mode/duration/rate 均返回 422。

### H5. 文件上传全量读入内存，无大小预检

**文件**：`main.py:62,96,150`  
**问题**：三个上传接口都 `await file.read()` 后才检查大小，恶意客户端上传 500MB 文件在检查前已占用 500MB 内存。

**修复**：read() 前检查 `file.size`，超限时提前返回 400；read 后二次校验（兼容 chunked 传输无 Content-Length 的情况）。

### H6. SRT 字幕时间轴漂移（块间 0.3s vs 实际 0 静音）

**文件**：`audio.py:103` vs `tasks.py:107,118`  
**问题**：`make_srt()` 假设每块间有 0.3s 间隙，但实际拼接用 `silence_ms=0`，10 段后字幕提前 3 秒，100 段后漂移 30 秒。

**修复**：`make_srt()` 添加 `gap` 参数（默认 0.0），调用方传入与 concat 一致的间隙值。

### H7. 后台任务 fire-and-forget 句柄未保存

**文件**：`main.py:124,132,140`  
**问题**：`asyncio.create_task()` 返回值未保存，可能被 GC 回收导致任务静默取消，异常变为 "Task exception was never retrieved"。

**修复**：添加全局 `_background_tasks: set`，`_run_bg()` 保存句柄并注册 `done_callback` 自动移除。

## 七、已知限制与后续建议

1. **长文本 TTS 性能**：>1000 字文本逐句串行调用 Edge-TTS，84 分片约需 2-3 分钟。后续可引入分片并发合成（受 Edge-TTS 速率限制，建议并发度 3-5）。
2. **任务取消机制**：当前客户端断连后后台任务继续执行。已通过 TTL 清理缓解，完整取消需引入 asyncio.CancelledError + ffmpeg 子进程 kill。
3. **CORS 全开放**：`allow_origins=["*"]` 适用于本地单机应用，多用户部署需配置域名白名单。
4. **/outputs 静态目录无鉴权**：task_id 为 12 位 hex（48bit），本地应用可接受，多用户场景需签名 URL。
5. **GPU 音色克隆**：已搁置，仅保留扩展接口（docs/ENGINE_EXTENSION.md）。
